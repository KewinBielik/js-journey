## How to learn to code:
- There is a github repo that has ideas for projects, it looks really cool and I think I could use it to learn - https://github.com/florinpop17/app-ideas.
- Someone says to focus on three things: API, Life cycle and version control (basically git) and Tech stack (the variety of technologies that you can use, express or react for example).
- Tim Kim (the guy who's video got me inspired) used https://www.freecodecamp.org/ and https://watchandcode.com/. For freeCodeCamp this guy "Stephen Mayuex" apparently done some tutorials. He also got a mentor in order to learn CRUD (Create, Read, Update, Delete) and they simulated a job enviromnent - the mentor treated him as real junior developer working at a company by using a jira Software. Then he also did Udemy courses on React and Node
- Use AI to ask you questions about concepts to test yourself.
- **Learn the layer below** - instead of learning another technology, try studying the problem which a technology solves. This is good approach because technologies keep changing but the problems often stay and still need solutions. EXAMPLE - How does a database avoid losing your data when the power dies halfway through a write?
- **Learn the real way to debug** - Using print statements all over the code is not ideal, this video talks abouts 3 steps approach to debugging but I feel like I am too dumb to understand it right now (https://www.youtube.com/watch?v=EFDVmd6ondM).
